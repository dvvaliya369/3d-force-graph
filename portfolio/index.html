About the Library

Powerful 3D network visualization made simple

🎨

Beautiful Visualizations

Create stunning 3D graph visualizations with customizable nodes, links, and interactive elements that bring your data to life.

⚡

High Performance

Built on ThreeJS and WebGL for smooth rendering of large graphs with thousands of nodes and links in real-time.

🔧

Highly Customizable

Extensive API with support for custom node geometries, link styling, force configurations, and interaction callbacks.

📱

Responsive Design

Works seamlessly across devices with touch support, responsive layouts, and adaptive rendering capabilities.

Key Features

Everything you need for advanced graph visualization

01

Force-Directed Layout

Automatic graph layout using d3-force-3d or ngraph physics engines for natural node positioning.

02

Interactive Controls

Zoom, pan, rotate with trackball controls. Click, hover, and drag nodes for dynamic interaction.

03

Custom Styling

Full control over node colors, sizes, shapes, link styles, arrows, particles, and materials.

04

Directional Links

Support for arrows, moving particles, curved links, and self-referencing connections.

05

Dynamic Updates

Real-time graph updates with smooth transitions and incremental data changes.

06

Extensible API

Access to ThreeJS scene, camera, and renderer for advanced customization and extensions.

Quick Start

Get up and running in minutes

Installation 
npm install 3d-force-graph
Import 
import ForceGraph3D from '3d-force-graph';
Usage 
const myGraph = ForceGraph3D()
  (document.getElementById('graph'))
  .graphData({
    nodes: [
      { id: 'node1', name: 'Node 1' },
      { id: 'node2', name: 'Node 2' }
    ],
    links: [
      { source: 'node1', target: 'node2' }
    ]
  });
